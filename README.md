# someNonsense.py

Convierte notas de MyBrain al formato de tareas de NoNonsense,
añadiendolas y generando necesariamente algo de nonsense...

## Instrucciones:

(Previamente exportar una copia de seguridad de la base de datos de NoNonsense y moverla fuera de la carpeta de backups,
Tambien exportar una copia de seguridad de la base de datos de MyBrain).

### en el celular:

 - Enviar una copia de ambas a la computadora que tenga linux y python3, en el directorio donde tengas esta script.

### en la computadora:

(en el directorio al que enviaste las copias)

python3 someNonsense.py MyBrain_Backup_xxxxxxxxxxxxx.json NoNonsenseNotes_Backup.json nuevoArchivo.json

luego enviar el nuevoArchivo.json al celular. 

### en el celular, nuevamente:

 - crear un directorio en el cual mover este archivo solo y renombrarlo a NoNonsenseNotes_Backup.json
 - en NoNonsense tocar en el menu hamburguesa>ajustes>copia de seguridad>Elige una carpeta(...)
 - seleccionar el directorio que creamos
